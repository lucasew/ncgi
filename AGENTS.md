# Agent Instructions

This repository uses `mise` to manage development tools and tasks.

## Tooling
- `mise`: Task runner and tool manager.

## Commands
- `mise run install`: Install dependencies.
- `mise run lint`: Run linters.
- `mise run test`: Run tests.
- `mise run codegen`: Update generated code.
- `mise run build`: Build the binary.
- `mise run ci`: Run CI pipeline (lint + test).

Please use `mise` for all development tasks to ensure consistency.
